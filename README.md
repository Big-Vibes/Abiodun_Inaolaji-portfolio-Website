### Code Architecture

**Component Structure:**
- `Layout.astro` — Meta tags, SEO optimization, responsive layout wrapper
- `Header.astro` — Navigation with siteLogo and smooth anchor links
- `Hero.astro` — Personal branding with email contact integration
- `Experience.astro` — Professional history with achievement summaries
- `Projects.astro` — Portfolio showcase with sticky card animations
- `About.astro` — Personal bio and mission statement
- `Section.astro` — Reusable section wrapper for consistent styling

**Configuration:**
- Centralized `SITE_CONFIG` for meta information
- `SITE_CONTENT` for dynamic data binding (zero hardcoding)
- Typed props throughout for runtime safety

## 🚀 Getting Started

Clone this repository to your local machine using Git.

```scheme
git clone https://github.com/Big-Vibes/Abiodun_Inaolaji-portfolio-Website
cd portfolio/astro-zen
```

| Command        | Action                                       |
| :------------- | :------------------------------------------- |
| `pnpm install` | Installs dependencies                        |
| `pnpm dev`     | Starts local dev server at `localhost:4321`  |
| `pnpm build`   | Build your production site to `./dist/`      |
| `pnpm preview` | Preview your build locally, before deploying |
